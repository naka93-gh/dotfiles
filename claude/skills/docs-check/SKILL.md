## 対象ドキュメント

- リポジトリ直下および配下の `CLAUDE.md`
- リポジトリ直下および配下の `AGENTS.md`
- `dev-docs/` 配下の `*.md`（存在すれば）

ユーザーグローバルの `~/.claude/CLAUDE.md` は対象外。

## 差分の取得

1. !`git status --short`
2. !`git diff --stat`
3. !`git diff --cached --stat`
4. staged も unstaged も空ならブランチ全体: !`git diff --stat main...HEAD`

差分がなければ「変更なし、チェック対象なし」と伝えて終了する。

## チェック手順

1. 対象ドキュメントを列挙する（Glob で `**/CLAUDE.md` `**/AGENTS.md` `dev-docs/**/*.md`）
2. 変更されたコード（必要なら本文を Read）と各ドキュメントを突き合わせる
3. 以下の齟齬を探す:
   - ドキュメントに書かれた仕様・I/O・コマンド・パス・関数名・モジュール名が、変更後のコードと一致しているか
   - 新しい挙動・オプション・モジュールが追加されたのにドキュメントに反映されていないか
   - 削除・改名された機能の記述が古いまま残っていないか
   - 設計方針（依存方向、レイヤー分割など）にコードが反している箇所があるか

## 出力フォーマット

齟齬がある場合:

```
## <ドキュメントパス>

- [L<行番号>] <記述の引用>
  - 現状: <現在のコード>
  - 提案: <どう更新すべきか>
```

齟齬がなければ「ドキュメントとコードに齟齬なし」と明記する。

## 対象外

- テスト追加のみなど、仕様に影響しない変更
- README.md / CHANGELOG.md（このスキルでは扱わない）
- コメント・docstring の文言ズレ
